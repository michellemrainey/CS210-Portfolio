# Chada Tech Clocks

## Project Summary

For this project, I created a program that displays both a 12 hour clock and a 24 hour clock. The user can choose to add one hour, one minute, or one second, and the clocks update based on the selection. The main purpose of the project was to practice using C++ functions, loops, user input, and formatting while building a program that actually responds to what the user enters.

## What I Did Well

I think I did a good job keeping the program organized and making sure each menu option worked the way it was supposed to. I also used separate functions instead of putting everything in one place, which made the code easier for me to follow. Testing each option one at a time also helped me make sure the hours, minutes, and seconds were updating correctly.

## Areas for Improvement

One thing I could improve is the way the program handles incorrect input. I could add more checks so the program responds better if the user enters something that is not one of the menu choices. I also think some parts of the code could probably be simplified as I get more comfortable with C++. That would make the program easier to update later.

## Challenges and Resources

The most challenging part for me was understanding how all of the different parts of the program worked together. I had to make sure that when the seconds or minutes reached their limit, the time would still update correctly. Breaking the project down into smaller steps and testing each part made it much easier for me to understand.

I used the course materials and Visual Studio while working on the project. I also used ChatGPT to help me understand the instructions, organize the steps, and troubleshoot when I got stuck.

## Transferable Skills

This project helped me get more comfortable with functions, loops, conditional statements, user input, and output formatting. I also got more practice with debugging and learning how to test one part of a program at a time. I know those are skills I will continue using in future programming classes and projects.

## Maintainability, Readability, and Adaptability

I tried to make the program easy to read by keeping the code organized, using functions, and using names that made sense. I also added comments so it would be easier to understand what different parts of the program were doing. Keeping the program organized this way would make it easier to go back later and make changes without having to start over.

I used ChatGPT to help me understand the instructions and steps for completing the project. I also used it for clarification and troubleshooting while working in Visual Studio. I reviewed the final work to make sure I understood what the program was doing.
